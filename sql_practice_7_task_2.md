# SQL. Практика 7. Задача 2

**Сложность:** Средняя  
**Платформа:** app.simulative.ru

## Задание

Напишите запрос, который из таблиц `coderun` и `codesubmit` выводит уникальные комбинации идентификаторов пользователей и идентификаторов задач, с которыми пользователи работали либо через выполнение кода, либо через отправку кода на проверку.

### Столбцы в результате

- `user_id`
- `problem_id`

### Примечание

Если пользователь работал с одной и той же задачей и через выполнение кода, и через отправку кода на проверку, то такая комбинация должна быть выведена только один раз (используйте `UNION`).
