## Задание

Из таблиц `language`, `languagetoproblem` и `problem` требуется вывести следующую информацию:

- Название языка программирования
- Название задачи
- Сложность задачи

### Дополнительные условия

Оставьте только те языки программирования, для которых существуют задачи.

### Столбцы в результате

- `language_name`
- `problem_name`
- `complexity`

### Сортировка

Результат отсортируйте по возрастанию `problem_name`.
