# SQL. Практика 5. Задача 4

**Сложность:** Лёгкая  
**Платформа:** app.simulative.ru

## Задание

Из таблицы `users` требуется вывести информацию о пользователях, которые зарегистрировались на платформе в течение 45 дней после `2022-01-01`.

### Столбцы в результате

- `id`
- `username`
- `date_joined`

### Сортировка

Результат отсортируйте сначала по убыванию поля `date_joined`, затем по возрастанию поля `id`.
