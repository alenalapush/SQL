## Задание

Из таблиц `users` и `codesubmit` требуется вывести следующую информацию:

- Логин
- Количество отправленных на проверку решений

### Столбцы в результате

- `username`
- `submission_count`

**Важно:** Обратите внимание, что название столбцов в вашем ответе должно в точности совпадать с условием.

## Дополнительные условия

Выведите только тех пользователей, которые зарегистрировались в 2021 году и у которых количество отправленных на проверку решений превышает 200.

## Сортировка

Результат отсортируйте по возрастанию `username`.

## Решение

```sql
select u.username,
    count(*) as submission_count
from users u
join codesubmit c
on u.id = c.user_id
where to_char(u.date_joined, 'YYYY') = '2021'
group by u.username
having count(*) > 200
order by username;
```
