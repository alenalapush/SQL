# SQL. Практика 8. Задача 12

**Уровень:** Средний

## Задание

Из таблиц `users`, `codesubmit` и `problem` требуется вывести следующую информацию по всем пользователям:

## Столбцы в результате

| Столбец | Описание |
|---------|----------|
| `id` | Идентификатор пользователя |
| `username` | Логин пользователя |
| `mode_problems` | Наименование задачи, которую пользователь наиболее часто отправлял на проверку |

**Важно:** Название столбцов в вашем ответе должно в точности совпадать с условием.

## Примечания

- Решите задачу с помощью функции `MODE()`
- Если у пользователя несколько задач с одинаковой максимальной частотой отправки, то выберите задачу по наименованию задачи в алфавитном порядке
- Если пользователь ничего не отправлял, то выведите `Пользователь ничего не отправлял`

## Сортировка

Результат отсортируйте по возрастанию поля `id`.
