# SQL. Практика 8. Задача 13

**Уровень:** Лёгкий

## Задание

Из таблицы `users` необходимо вывести массив логинов пользователей в отсортированном виде сначала по убыванию даты и времени регистрации, затем по возрастанию логина.

## Столбцы в результате

| Столбец | Описание |
|---------|----------|
| `array_username` | Массив логинов пользователей |

**Важно:** Название столбцов в вашем ответе должно в точности совпадать с условием.
