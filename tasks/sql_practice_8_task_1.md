# Задание

Из таблицы `problem` необходимо вывести уровень сложности задач и количество задач для каждого уровня сложности.

## Столбцы в результате
- `complexity`
- `count_of_problems`

**Важно:** Названия столбцов в ответе должны точно совпадать с условием.

## Сортировка
Результат отсортировать по возрастанию `complexity`.
