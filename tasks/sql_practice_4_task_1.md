# SQL. Практика 4. Задача 1

**Сложность:** Лёгкая  
**Платформа:** app.simulative.ru

## Задание

Из таблицы `users` требуется вывести следующую информацию о пользователях:

- Идентификатор
- Логин
- Текстовое описание идентификатора формата "Идентификатор пользователя равен x", где x — значение `id`

### Столбцы в результате

- `id`
- `username`
- `text_user_id`

### Сортировка

Результат отсортируйте по возрастанию поля `id`.
