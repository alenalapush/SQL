# SQL. Практика 4. Задача 3

**Сложность:** Средняя  
**Платформа:** app.simulative.ru

## Задание

Из таблицы `users` требуется вывести следующую информацию о пользователях:

- Идентификатор
- Логин
- Количество очков опыта на платформе
- Группа пользователя по количеству очков опыта на платформе

**Правила присвоения группы:**

| Условие | Группа |
|---------|--------|
| `score > 300` | Мастер |
| `score > 150` | Эксперт |
| `score > 75` | Продвинутый |
| Остальные случаи | Новичок |

### Столбцы в результате

- `id`
- `username`
- `score`
- `group_user`

### Сортировка

Результат отсортируйте по возрастанию поля `id`.
