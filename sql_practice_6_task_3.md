# SQL. Практика 6. Задача 3

**Сложность:** Лёгкая  
**Платформа:** app.simulative.ru

## Задание

Из таблицы `users` требуется вывести информацию о пользователях, которые зарегистрировались на платформе в 2021 году **либо** имеют количество очков опыта на платформе строго больше 100.

### Столбцы в результате

- `id`
- `username`
- `email`
- `date_joined`
- `score`

### Сортировка

Результат отсортируйте по возрастанию поля `id`.
