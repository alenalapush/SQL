# SQL. Практика 6. Задача 7

**Сложность:** Лёгкая  
**Платформа:** app.simulative.ru

## Задание

Из таблиц `users` и `company` требуется вывести информацию о всех пользователях, которые зарегистрировались в 2021 году:

- Идентификатор пользователя
- Логин пользователя
- Дата и время регистрации пользователя
- Название компании к которой относится пользователь

### Столбцы в результате

- `id`
- `username`
- `date_joined`
- `company_name`

### Примечание

Если пользователь без компании, то выводите `Без компании`.

### Сортировка

Результат отсортируйте по возрастанию `id`.
