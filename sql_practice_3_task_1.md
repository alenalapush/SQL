# SQL. Практика 3. Задача 1

**Сложность:** Лёгкая  
**Платформа:** app.simulative.ru

## Задание

Из таблицы `users` требуется вывести следующую информацию о пользователях:

- Идентификатор
- Логин
- Имя
- Фамилия
- Имя в нижнем регистре
- Фамилия в верхнем регистре
- Длина логина

### Столбцы в результате

- `id`
- `username`
- `first_name`
- `last_name`
- `lower_first_name`
- `upper_last_name`
- `length_username`

### Сортировка

Результат отсортируйте сначала по убыванию `length_username`, затем по возрастанию `id`.
