# SQL. Практика 6. Задача 4

**Сложность:** Лёгкая  
**Платформа:** app.simulative.ru

## Задание

Из таблиц `testquestion` и `testanswer` требуется вывести следующую информацию:

- ID вопроса
- Текст вопроса
- Тег вопроса
- Текст правильного ответа

### Дополнительные условия

Оставьте только правильные ответы на вопросы.

### Столбцы в результате

- `question_id`
- `question_value`
- `question_tag`
- `correct_answer_value`

### Сортировка

Результат отсортируйте по возрастанию `question_id`.
