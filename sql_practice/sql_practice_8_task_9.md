# SQL. Практика 8. Задача 9

**Уровень:** Средний

## Задание

Из таблиц `company` и `users` требуется вывести количество активных и неактивных пользователей по всем наименованиям компаний.

## Столбцы в результате

| Столбец | Описание |
|---------|----------|
| `company_name` | Наименование компании |
| `cnt_active_users` | Количество активных пользователей |
| `cnt_not_active_users` | Количество неактивных пользователей |

**Важно:** Название столбцов в вашем ответе должно в точности совпадать с условием.

## Примечание

Если в компании нет активных или неактивных пользователей, то выведите 0.

## Сортировка

Результат отсортируйте по возрастанию `company_name`.
