# SQL. Практика 8. Задача 11

**Уровень:** Лёгкий

## Задание

Из таблицы `company` и `users` требуется вывести фамилии пользователей в виде списка по всем наименованиям компаний, разделяя фамилии запятой и пробелом (`, `) в отсортированном по возрастанию поля `email`.

## Столбцы в результате

| Столбец | Описание |
|---------|----------|
| `company_name` | Наименование компании |
| `list_last_names` | Список фамилий пользователей через `, ` |

**Важно:** Название столбцов в вашем ответе должно в точности совпадать с условием.

## Примечания

- Оставьте только те компании, у которых есть пользователи
- Исключите пользователей, у которых нет фамилии

## Сортировка

Результат отсортируйте по возрастанию `company_name`.
