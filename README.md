# PlantUML Diagrams

Коллекция диаграмм для практических заданий.

## Диаграммы

- `practice.puml` - Базовые диаграммы
- `practice2.puml` - Диаграмма 2
- `practice3.puml` - Диаграмма 3
- `practice4.puml` - Диаграмма 4
- `practice5-1.puml`, `practice5-3.puml`, `practice5.puml` - Диаграмма 5
- `practice6.puml` - Диаграмма 6
- `practice7.puml` - Диаграмма 7
- `practice8.puml` - Диаграмма 8
- `test.puml` - Тестовая диаграмма

## Использование

Для просмотра диаграмм используйте PlantUML:
```bash
plantuml -tpdf <file.puml>
```
