# SQL. Практика 8. Задача 14

**Уровень:** Средний

## Задание

Из таблицы `users` и `codesubmit` необходимо вывести следующую информацию о пользователях, которые отправляли код на проверку:

- Идентификатор пользователя
- Логин пользователя
- Массив уникальных идентификаторов задач, которые пользователи отправляли на проверку в отсортированном виде по возрастанию поля `problem_id`

## Примечания

- Отправленный на проверку код находится в таблице `codesubmit`

## Столбцы в результате

| Столбец | Описание |
|---------|----------|
| `id` | Идентификатор пользователя |
| `username` | Логин пользователя |
| `unique_problem_ids_array` | Массив уникальных идентификаторов задач |

**Важно:** Название столбцов в вашем ответе должно в точности совпадать с условием.

## Сортировка

Результат отсортируйте по возрастанию поля `id`.
